# optional -- not part of the lightweight flow

`feedback_prep/` and `feedback_run/` live here because they are not merged
into the main pipeline flow. Nothing under this folder runs as part
of `messageix/run.R` or the lightweight three-step flow
(`docs/lightweight-mode.md`); each script still runs standalone from the
MAgPIE model root, same commands as before the move.

This code needs further validation before wider use.
